## What was built

Started from scratch and shipped v0.1.2 of the Memento Mori Obsidian plugin — a lifetime visualizer rendered as an L-system Hilbert-like curve on an HTML Canvas with d3-zoom pan/zoom.

### Core plugin (v0.1.0 → v0.1.1 → v0.1.2)

- **Geometry** (`geometry.ts`): L-system order 7, two cells per point (rectangles on straights, triangle pairs on turns), world-space inset polygon for gaps between cells.
- **Data layer** (`data.ts`): Parses Obsidian frontmatter for `mm: range` and `mm: event` entries. Outputs per-day color arrays per perspective + label entries. Exports `GRAY`, `EVENT_COLOR`, `DEFAULT_PERSPECTIVE`.
- **View** (`main.ts`): ItemView with d3-zoom, perspective switcher (Obsidian Menu), zoom-to-today button. Today's cell is theme-inverted (bg fill + text border). Future plain cells 0.2 alpha, future event cells 0.5 alpha.
- **Settings** (`settings.ts`): `entriesDir`, `birthDate`, `curveSkew` (degrees subtracted from 90° for turnAngle).
- **Label system**: 4-phase pipeline — pre-count per anchor → collect candidates → sort by minZoom → occlusion cull with centered combined bounding boxes → draw stacked centered.
  - `wrapToRatio`: binary search for most even word split within 5:1 ratio (ratio applied to full stack height).
  - Same-day stacking: combined box tested at the new label's own priority level.
- **`mm-ongoing`**: End date tracks today; end day not marked and end label suppressed.
- **`mm-minzoom`**: Accepts quoted string or number; hides labels below the given zoom level.
- **Dark mode**: `EVENT_COLOR` sentinel resolves to `--text-normal` at draw time.
- **Mobile**: `isDesktopOnly: false` in manifest.

### Tooling

- GitHub Actions release workflow triggered on `v*` tags; publishes `main.js` + `manifest.json`.
- `npm version` lifecycle script auto-syncs `manifest.json` version.
- `test-render.html`: headless Chrome visual testing harness (inlines geometry, fake data, full label pipeline).

## Key design decisions

| Decision | Rationale |
|---|---|
| `TOTAL_CELLS = 32768 = 2 × 4^7` | Two shapes per L-system point at order 7 |
| `fitScale` stored on view | HUD zoom = `log2(k / fitScale)`; zoom-to-today targets 4.5 |
| Priority sort before occlusion | Lower minZoom wins; same-day labels tested at new label's own priority (not elevated) |
| Centered label stack box | `{t: cellSy − totalH/2, b: cellSy + totalH/2}` — commit and draw positions match exactly |
| `wrapToRatio` binary search | Monotone property makes binary search exact; ratio vs. full stack height not individual label |
